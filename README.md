# 课间

**宣传委员-冰冰板 制作**

Android 手机/平板和 Windows 电脑可直接安装的课程表。无账号、无广告、无订阅，日常课程、考试和待办在本机离线使用。

## 下载

请到 [最新发布](https://github.com/bingbingban07/kejian-updates/releases/latest) 下载：

- `kejian-android.apk`：Android 10 及以上手机和平板。
- `kejian-windows-x64.exe`：Windows 10/11 x64 安装程序。
- `kejian-windows-portable.zip`：Windows 便携包，完整解压后运行 `kejian.exe`。

首次打开必须阅读课表说明并确认。课程可能因选课、体育项目和分班而不同，请核对本人教务课表和学校通知。

**课表只保存在本机，不会自动更新。收到调课通知后，必须手动调整或导入最新课表。手机、平板和电脑之间不会自动同步。**

## 应用更新

在“设置 → 应用更新 → 检查更新”主动检查和下载。仅检查/下载时联网，不上传个人课表、考试或待办。更新清单使用独立 Ed25519 发布签名；下载包校验大小和 SHA-256，Android 还核对应用包名、较新版本和原发布签名，再由系统确认安装。

此仓库仅存放公开发布说明、安装包与签名版本清单。完整源码另行提供，个人数据、原始截图和发布密钥不在此仓库中。
